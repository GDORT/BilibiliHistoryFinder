## 4. ADR 规范

文件名：`doc/adr/NNNN-短标题.md`，模板固定六段。

```
# NNNN · <一句话决策>
- 状态：已接受 | 已取代（被 NNNN）
- 日期：YYYY-MM-DD
- 背景：为什么必须做这个决定（2–3 句）

- 理由：为什么不选另一条路
```

1. **事实只写一次**：能力数、端口 `8765`、`ANALYZER_DB` 路径、`PAGE=60` 等，只在 `现状.md` 定义；其余文档一律**链接引用**，不复制。每多抄一份，未来就多一个需要同步的失败点。

3. **轮次记录剪切而非积累**：`待办.md` 只留未完成；做完的**剪**到 `log/`。
4. **闭环即冻结**：审查 / 评估类文档一旦所有条目都有处置结论 → 移入 `archive/`；新发现**开新报告**，不追加章节。
