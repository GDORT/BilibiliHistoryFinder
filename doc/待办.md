### #40 详查：`duration` 缺失的根因与**恢复路径**（2026-10-05 重新查证）

> ⚠️ **本段推翻 2026-10-03 的「无法修复」结论。** 旧结论只查了 Finder 侧（本地库 `raw_json`），
> **漏查 Analyzer 侧的原始 JSON** —— 那里恰好有完整数据。

#### 一、缺失现状（未变）

| 年表 | 条数 | `duration` 缺失 | `progress` 分布 |
| --- | --- | --- | --- |
| 2020 / 2021 / 2022 / 2023 / 2024 / 2025 | 19/132/46/39/63/64（**363**） | **各 100%** | **全 0，无一条 `-1`** |
| 2026 | 4198（10-05 核，已从 3685 增长） | 2.6% | `-1` 为主 |

本地库 `data/bilibili_history.db` 缺 462 条（10.2%，`business='archive'` ×442）。**受影响判据**：`store.py` 的 95% 判据 ＋ `engine.py` 三条规则（`接近看完`/`误触-短暂观看`/`短视频碎片`）因**缺分母**而无法判定 —— 实测 `progress == 0` 的 847 个视频里 **393 个**因此未被任何规则接住。

#### 二、⭐ 关键发现：`duration` 本来就在**历史接口返回里**（2026-10-05 实测）

Analyzer 保留着**采集时的原始 JSON**：`output/history_by_date/<年>/<月>/<日>.json`。

| 实测项 | 结果 |
| --- | --- |
| JSON 顶层字段 | `author_* · badge · cover · **current** · **duration** · **history** · is_fav · is_finish · kid · **progress** · **total** · uri · videos · view_at` |
| **`duration` 覆盖** | **4172 条中 4098 条非零 ＝ 98.2%** |
| `bvid` 位置 | **不在顶层**，在 `history` 子对象里（`history.bvid/oid/cid/epid/business/page`） |
| `duration=0` 的 74 条 | `history` 子对象里**也**没有 `duration` → 属接口本身不返回（直播/专栏等），**非采集缺陷** |

⇒ **B站历史接口本身就返回视频时长。** 2020–2025 那批 `duration` 全 0，**是当年采集时该字段未落盘**（旧版采集器），**不是接口限制、也不是数据本质缺失**。

**我上次的判断错在哪**：只查了 Finder 本地库的 `raw_json`（那里确实没有 `duration`），就推断「采集时压根没存」——**漏了 Analyzer 侧的原始 JSON 才是权威**。

#### 三、⚠️ 但**原始 JSON 只剩 2026**

`output/history_by_date/` 下**只有 `2026/`**（83 个文件，覆盖 05-15 ~ 10-03），**2020–2025 的原始 JSON 已被清理**（`find_latest_local_history` 只保留最近若干天）。且 `video_library.db`（`video_details` 表所在库）**不存在** → Analyzer 那套「逐视频补详情」的链路从未成功落盘。

⇒ **2020–2025 的 `duration` 无法从 Analyzer 侧直接取回**（原始 JSON 没了、详情库没了）。

> ⚠️ **2026-10-05 已解决（结论翻转）** —— 上面这条只穷尽了「从 Analyzer 取」这一条路。**B3 实测找到第四条路**：B站**详情接口 `/x/web-interface/view?bvid=` 无需 SESSDATA、可按 bvid 查任意历史视频**（不受 `history/cursor` 的三个月限制）→ **363 条补全 344 条（94.8%）**。已按 **overlay 方式**落地（见上表）。

#### ⚠️ 2026-10-05 补充：一条**方法论教训**（来自 `#41`）

给 `engine.py` 补单测时撞出 `#41`（`duration=0` 被规则误判「短视频碎片」），**顺带推翻了本节此前的收益估算方式**：

| 口径 | 数值 |
| --- | --- |
