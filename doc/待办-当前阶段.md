#### T8 白话版：这个功能在干什么 + 怎么验

**一句话**：Finder 每次真的从 Analyzer 拉完数据后，会顺手给自己留一份**本地快照**（把 Analyzer 主库 + 本地库各拷一份，放进 `data/backup/<时间戳>/`）。规则是 **「新增 ≥ 200 条才自动留一份；最多留 5 份，第 6 份进来时删掉最旧的」** —— 防止 `data/backup/` 无限膨胀。

**分两件事验，你可以只做第 (A) 件。**

**(A)「下次要不要自动备份」—— 只读，现在就能做（推荐）**

```

```

只看这几项就够：

| 字段                        | 它是什么意思                 | 08:4x 实测值  |
| ------------------------- | ---------------------- | ---------- |
| `policy.delta_threshold`  | 新增多少条算「够格备份」           | `200`      |
| `policy.keep`             | 快照最多保留几份               | `5`        |
| `delta_since_last_backup` | 距上次备份之后又新增了多少条         | `387`      |
| `would_trigger`           | **下次真拉完数据后，会不会自动备份一份** | `true` ✅   |

#### 备注来源说明（T4 那个现象的答案）
