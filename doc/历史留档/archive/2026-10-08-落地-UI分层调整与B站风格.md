## 二、② B站风格对齐（本轮新增，用户追加要求）

> **依据**：本仓参考源码 `doc/BiliHistoryFrontend-master/`（一个模仿 B站视觉的历史查看器）的
> 设计规格 —— 页面底色 `#F1F2F3`、主色 `#fb7299` / 进度色 `#FF6699`、卡片 hover ＝ 粉色描边 ＋ 阴影、
> 封面 `aspect-video`（16:9）、进度条 `h-0.5` 黑底 ＋ 粉填充、右下角 `progress/duration` 角标。

| 位置 | 改前 | 改后（对齐 B站） |
| --- | --- | --- |
| 页面底色 `--bg` | `#f4f5f7` | **`#f1f2f3`**（B站网页版底色） |
| 顶栏 `.topbar-inner` | `padding:10px`（高度不定） | **固定高 `56px`**，垂直居中（B站头部高度观感） |
| 品牌 `.brand` | 灰字 15px/600 | **粉字 `--pink` 16px/700**（B站标识色） |
| 搜索框 `.search input` | 灰底 + 描边 | **`#f1f2f3` 底 + 透明描边**，聚焦才显形（B站搜索） |
| 卡片 `.item:hover` | 仅阴影 `rgba(0,0,0,.08)` | **粉色描边 `border-color:--pink` ＋ 阴影 `0 0 12px rgba(0,0,0,.1)`** |
| 封面 `.cover` | 固定 `height:144px` | **`aspect-ratio:16/9`**（真 16:9，各断点不拉伸） |
| 进度条 `.pbar` | `4px`，`rgba(0,0,0,.35)` 底 | **`2px`，黑底 `rgba(0,0,0,.6)` ＋ 粉填充 `#FF6699`** |
| 时长/角标 `.dur` | 圆角 3px、`11.5px` | **圆角 2px、`11px`、`rgba(0,0,0,.5)`**（B站角标） |
| UP 主名 `.up:hover` | 蓝 `--blue` | **粉 `--pink`**（与参考应用一致） |

⚠️ **对齐的是「与 B站同源的功能」**（浏览层：分类 tab / 状态筛选 / 卡片列表 / 搜索 / 时间侧栏）；
Finder 自身与运维入口的**功能结构不动**（P2 分离原则不变）。

## 三、约束遵守（⭐ 本轮的硬红线）

`CAP_DOM`（能力→DOM 映射）与 A1 字面基线 `BASELINE_SELECTORS` 均**按 id 选择器**工作，故：

1. **只搬位置、不改 id** —— 所有按钮 / 输入框 `id` 原样保留，仅改父容器与摆放位置。
   ⇒ `dev/test_capabilities.py::T2.8` 与 `dev/e2e/smoke_frontend.py::G2.0b` **均未变红**。
2. **`UNAVAILABLE_MODE` 保持 `'gray'`**（改 `hide` 是阶段 6，见 §六）。
3. **卡片结构不变** —— 仍是 `li.item` ＋ `.remark-text`（A1 `G1.3` / `G2.1` 的判据依赖）。
4. 视觉改动**只在 CSS**，不触碰任何 DOM 结构与函数签名。
