## 五、⭐ 本轮踩的坑（最值得留存的部分）

> 这一节是本稿最有价值的部分。每条都是**实测撞出来**的，不是设想。

### 5.1 ⭐⭐ 同源断言会假绿（G2 撞出，设计级教训）

**现象**：G2 的期望集合是「**从浏览器读** `CAP_DOM` 换算」而来。
负向验证时删掉 `CAP_DOM.export` 的一个选择器 → **断言仍 34/34 全绿**。

**原因**：改实现与改断言**同步变化 → 一起错 → 假绿**。
「真实产出驱动」（P4）有固有弱点：它保证"页面与断言同源"，**不保证"断言独立于被测"**。

**修法**：加一条**独立基线**（脚本内**字面清单**，与 `app.js` 无关）→ 重测立即被抓住（35/36）。

⇒ **推广规则**：凡「期望」与「被测」同源的断言，都要另配一条外部基线。

⚠️ **代价**（明账，不是隐患）：阶段 6 改 UI 时必须同步那份清单。

### 5.2 夹具的三条事实（都写进 `make_fixtures.py` 注释了）

① **`auto_skip` / `auto_skip_reason` 落库值完全无效** —— `store.classify_record()`
会**按规则重算**；而 `_view_ok` 的 `skipped`/`stale` 视图判的是 **reason 前缀**
（`auto_skip::` / `stale::`）⇒ **夹具无法直接指定分类**，只能设计记录特征去命中规则。

② **`_BASE` 必须锚定真实 `now()`，不能写死时间戳** —— `stale` 规则判
`view_at_age_days > 90`，而 `now()` 是**真实时间**。写死 `1757000000`（2025-09）后，
"3 天前"的记录在 2026-10 跑出来是 **401 天前** → 全部命中 `stale` →
`needs` 视图返回 **0 条**。**踩了两次才找对**。

③ **`duration=0` 是「有值」不是「缺值」** —— `sort_value(0)` 返 `(0, 0.0)`（有值段）；
**只有 `None`** 返 `(1, 0)`（缺值段）⇒ `#42` 的"缺值恒末尾"只对 `None` 成立，
`0` 应排在**有值段最前**。我第一次把 `0` 当缺值，被探针当场纠正。

⚠️ **附带坑**：**STALE 组的 `duration` 必须 ≥ 60**，否则先命中规则 3「短视频碎片」
→ reason 变 `auto_skip::` → **掉出 stale 视图**（实测到 stale 一度返回 28 = all）。

### 5.3 校准后的实测值（改夹具特征后**必须**重跑）

`needs=23 / skipped=4 / stale=6 / finished=6 / archived=0 / all=39`；
`duration` 分布 `NORMAL=24 / ZERO=7 / NULL=9`。写在 `expect_view_counts()` 里。

### 5.4 工具链的坑（省得下次再撞）

| 坑 | 表现 | 正解 |
| --- | --- | --- |
| `with sync_playwright()` 退出后再 `browser.close()` | `Error: Event loop is closed!` | 不要重复关闭，`with` 已托管 |
| `rmtree` 后目录壳仍可见 | 以为没清干净 | Windows 删除延迟、内容已空；**不要当场断言 `not exists()`** |
| 模块级 `assert` | import 期抛`AssertionError`，冒烟脚本**崩掉**而非可读失败 | 改`selfcheck()` 返回可读报告 |
| bash heredoc 里的 `$(...)` | SyntaxError（被 shell 当命令替换） | 含 `$(`/反引号的 Python 代码**写成临时 `.py` 再执行** |
| 参数名叫 `dir` | 遮蔽内置，且调用处签名不符 → TypeError | 用 `direction` |
| CRLF 文件用 Python 文本读写 | `bareLF` 混进 bat | `newline=""` ＋ 事后 `replace(\r\n→\n→\r\n)` 并断言 `bareLF==0` |
| `rm -f "$TEMP/x"`（路径含盘符） | 被安全规则**静默拒绝** | `cd "$TEMP" && rm -f x`（相对路径） |
| 负向验证副本放子目录 | `ROOT` 上溯层数变化 → 找不到 `src/` | **原位改写 ＋ 跑完还原** |
