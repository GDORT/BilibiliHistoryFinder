# 0002 · 移除 `BHF_PORT` 环境变量，端口只由配置文件决定

- 状态：已接受
- 日期：2026-09-25
- 背景：为实现「⑥ 应用变更 / ⑦ 重启服务」的隔离实测，曾给 `get_web_port()` 加过 `BHF_PORT` 环境变量覆盖，用于在不干扰在跑实例的前提下另起一个测试实例。
- 决策：**移除**该环境变量。监听端口只由 `config.json` 的 `web_port` 决定（缺省 `8765`）。
- 理由：该覆盖只为一次性测试而设。留下它等于让"端口"有两个真相源 —— 排查"服务到底监听在哪个端口""是不是有两份实例"时会多出一条隐蔽分支；本项目追求零依赖、零隐藏开关，隔离测试可用独立副本目录达成，不需要端口覆盖。
- 影响：`src/server.py` 的 `get_web_port()`；文档中不得再出现"用环境变量换端口"的说法。**要换端口请改配置文件。**
