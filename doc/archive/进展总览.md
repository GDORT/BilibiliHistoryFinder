## 五、关键实现细节与踩过的坑

### 5.1 运行机制

- **⑥ 应用变更的六分支**：按改动类型自动判定 —— `none` / `reload`（`importlib.reload` 覆盖 store / engine / rules，约 0.1s）/ `static`（只提示硬刷新）/ `restart`（服务层变更，约 3s）/ `manual`（`start.bat` 本身改了）/ `blocked`（护栏：120s 内 3 次 → 拒绝并给 `retry_after`）。
- **重启链的权威判据是文件握手**：`data/run/relaunch.flag` —— `start.bat` 只看这个文件在不在，**不依赖 `%errorlevel%`**（因为退出码曾被吞）。
- **`CODE_BASELINE` 在进程启动那刻取磁盘快照**：所以启动后再制造一次改动才会看到 `pending`；点 ⑥ 会走完整链路，测完新基线自动吸收。

### 5.2 踩过的坑（可复用教训）

1. **Windows 控制台 QuickEdit「选中即冻结」**：窗口被鼠标选中时，向它的**任何 `stdout/stderr` 写操作都会阻塞**。修复 = 输出丢一次性守护线程（`_safe_print`）+ 重启关键路径**只写文件**，全文件**零裸 `print`**。
2. **守护线程里的 `os._exit` 会被解释器收尾吞掉**（退出码变 0）→ 退出码必须**主线程决定**（`_serve_forever_and_exit`）。
3. **回归必须与生产同构**：在生产拓扑里测（真 `ThreadingHTTPServer` + 主线程 `serve_forever` + 工作线程发起），否则测的是副本。上任教训：直接在主线程调 `_restart_after_response()` 天然得 42，**放过了真 bug**。
4. **折叠 ≠ 只留最新**：`progress=-1`（历史某次已看完）会被「只留最新会话」抹掉 → **7 条**误判为「需要观看」，且随使用持续增长。修法是状态聚合而非简单去重。
5. **「互动补充：…」备注不是 Finder 写的**：B站观看历史只保留近三个月，Analyzer 会把收藏 / 点赞 / 投币补进历史库并写这条溯源标记（`interaction_records.py` 写死前缀）。Finder 只读展示。
6. **清理逻辑容易"漏挂一条路径"**：`_prune_backups` 原先只挂在自动路径 → 手动连点会无限堆积。
7. **本机 HTTP 代理会吃掉 `127.0.0.1`**：命令行 `curl` 直连返 **502**（看着像服务挂了）→ 加 `--noproxy "*"`；Python 脚本进程内清 `*_proxy` 环境变量。**网页按钮不受影响。**
8. **改常量要逐个覆盖**：`RUN_DIR` / `RESTARTS_FILE` / `RESTART_LOG` / `RELAUNCH_FLAG` 都是 `server.py` **模块顶层**用 `RUN_DIR` 拼死的 —— 改 `RUN_DIR` 不会连带改。
9. **测试优先"内存覆盖"而非"改磁盘配置"**：`_fetcher_cfg()` 优先级 = `FETCHER_OVERRIDE`（内存）> 环境变量 > `data/fetcher_config.json` > 默认 → 测试时只改内存，省掉「必须还原」整步。

### 5.3 文档与文件约定

- 表格内**裸 `|` 会破坏 GFM 列结构**（行内代码反引号挡不住）→ 用 `·` 或 `\|`。
- `doc/待办-当前阶段.md` 约定 **LF**（Obsidian 编辑过）；`README.md` / `start.bat` 约定 **CRLF**；`.py` 为 LF。
- `start.bat` 纯 ASCII、**不要写 `chcp 65001`**（批处理中途切代码页是 cmd 的已知坑，会吃掉后续行首字符）。
- 大段中文脚本别用 Bash heredoc 写 Python（易触发 `SyntaxError`）→ 先用 Write 落文件再执行。
