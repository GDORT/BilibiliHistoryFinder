## 一、这是什么

把 Finder 的本地能力（规则引擎 / 分类 / 排序）**移植到浏览器里**，直接作用在 B站历史页上：
自动把你看过的记录抓下来存到本地、按你定的规则打角标、分类查看、导出给 Finder。

**不依赖 Analyzer、不依赖后端、不回写 B站** —— 数据全部来自页面自己发的请求，脚本只"旁听"。

| | |
| --- | --- |
| 装在哪 | Tampermonkey（Chrome/Edge/Firefox 均可） |
| 作用页面 | `https://www.bilibili.com/history`（历史页） |
| 数据存哪 | **你浏览器的 IndexedDB**（不经过任何服务器） |
| 当前版本 | **0.4.1** |

## 二、能力清单（当前实际有的功能）

| # | 功能 | 在哪 | 说明 |
| --- | --- | --- | --- |
| 1 | **自动抓取历史记录** | 页面加载时自动 | 旁听 `history/cursor` 响应，逐页入库；**你滚动多少就抓多少** |
| 2 | **实时分类角标** | 每张历史卡片 | `已看完` / `已跳过·原因` / `已搁置·原因` / `已恢复`；点角标可**手动取消**自动判定 |
| 3 | **顶栏分类读数** | 页面顶部固定条 | `N看完 · N跳过 · N搁置 · N待观看`，实时更新；悬停看**逐条规则命中数** |
| 4 | **分类视图** | 顶栏「分类」 | 五个 tab（全部/已看完/已跳过/已搁置/待观看）清单：标题·UP主·进度·时长，点标题新窗口打开 |
| 5 | **可视化规则编辑器** | 顶栏「规则」 | 表单调规则：多规则单选激活、新增空白/预设、分组与条件增删、实时冲突提示 |
| 6 | **导出 JSON** | 顶栏「导出」 | 下载全部记录，**供 Finder 读回**（同一 schema） |
| 7 | **SPA 分页跟随** | 自动 | 滚动加载的新卡片自动补标（MutationObserver） |

> **规则不匹配任何条件 = 待观看**，按设计**不显示角标**（避免满屏标签）。
> 想看全部记录 → 顶栏「分类」→ 切到「待观看」。

## 三、怎么装（三步）

1. 浏览器装 **Tampermonkey**（Chrome 商店 / Edge 扩展商店）。
2. Tampermonkey → 新建脚本 → 把 `bili_history.user.js`（仓库根） **整份内容**粘进去 → 保存。
3. 打开 **https://www.bilibili.com/history**（**需登录**），页面顶部出现蓝色「BHF 历史增强」条即成功。

**更新版本**：重复第 2 步（整份替换旧内容）。

> 脚本头三行元数据**不要改**：`@run-at document-start`（晚于它拦不到首批请求）· `@grant none`（与页面共享 window 才能 hook）· `@match …/history*`。

## 四、界面说明

### 顶栏（页面顶部固定）

| 元素 | 含义 |
| --- | --- |
| `BHF 历史增强` | 标题 |
| `N看完 · N跳过 · N搁置 · N待观看` | **实时分类读数**；悬停显示逐条规则命中数（用于判断"规则没命中"还是"命中了没显示"） |
| `已抓取 N 条` | 本次会话旁听到的记录数 |
| **分类** | **开关**分类视图面板（默认关） |
| **规则** | **开关**规则抽屉（可视化规则编辑器，默认关） |
| **导出** | 下载 JSON |

### 悬浮面板显隐（v0.4.1 起 · 两个面板都默认关闭）

| 元素 | 位置 | 默认 | 打开 | 关闭 |
| --- | --- | --- | --- | --- |
| 分类视图 | 左侧 | **关** | 顶栏「分类」 | 顶栏「分类」再点一次，或面板内右上 `×` |
| 规则抽屉 | 右侧 | **关** | 顶栏「规则」 | 顶栏「规则」再点一次，或面板内右上 `×` |

- **关掉的偏好会被记住**：下次打开历史页不会自己弹出来（存 `localStorage` 的 `bhf.ui.panels`，与数据存储无关）。
- 顶栏那 34px 细条常驻，只放读数和开关，不遮挡内容。
- **面板关着不影响角标** —— 角标直接打在原卡片上。
- 清浏览器缓存即恢复出厂默认（两个面板都关闭）。

### 分类视图面板（顶栏「分类」）

- 五个 tab：**全部 / 已看完 / 已跳过 / 已搁置 / 待观看**。
- 每行显示：标题（可点，新窗口打开）、状态标签、进度（`已看 62% · 10:00`）、命中的规则名、UP主。
- 最多显示前 300 条；空分类显示「该分类暂无记录」。

### 规则抽屉（顶栏「规则」）—— 两部分

**上半：可视化规则编辑器**（日常用这个）

| 控件 | 作用 |
| --- | --- |
| 规则列表 ＋ 单选圆点 | 切换哪条规则生效（**始终恰好一条** active） |
| ＋ 新增空白 / ＋ 新增预设 | 新建规则（空白=起步；预设=复制默认规则） |
| 分组区 | 每组＝**分组名 ＋ 动作**（自动跳过/自动搁置）＋ 条件列表；可增删组 |
| 条件行 | **字段下拉 ＋ 运算符下拉 ＋ 值输入**（数值字段自动按数字存） |
| 底部消息条 | 实时校验：`规则有效` / `提醒：…`（冗余条件）/ `硬冲突：…`（**拒存**） |
| 保存并应用 / 放弃修改 | 保存后立刻重算读数并**重打角标** |

**下半：原始 JSON**（高级用法）—— 直接编辑规则 JSON，粘贴 schema 导入/导出。

### 卡片角标

| 角标 | 含义 | 可点？ |
| --- | --- | --- |
| `已看完`（绿） | 看完（B站 `is_finish`） | 否 |
| `已跳过·原因`（粉） | 命中规则 → 自动跳过 | ✅ 点一下变「已恢复」（手动取消） |
| `已搁置·原因`（橙） | 命中规则 → 自动搁置（久未看） | ✅ 点一下取消 |
| `已恢复`（灰） | 你手动取消过自动判定 | ✅ 点一下恢复规则判定 |

## 五、数据存在哪 / 导出给谁

### 存储（全部在你自己浏览器）

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 历史记录（原始） | IndexedDB `bhf_history` → `raw` store | **原样存整条响应**，永不丢字段 |
| 历史记录（归一） | 同库 → `derived` store | 规范化后的分类用字段，主键 `kid` |
| 规则 | `localStorage.bhf_rules` | 多规则 + 哪条生效 |
| 手动取消记录 | `localStorage.bhf_overrides` | 你点角标取消的 kid |
| 元信息 | 同库 → `meta` store | 版本等 |

### 导出（唯一的对外出口）

点顶栏「导出」下载 `bhf-history-<时间戳>.json`，内容：
```
{ exported_at, count, records: [ { kid, bvid, title, author_name, duration, progress,
                                   is_finish, view_at, business, uri, … } ] }
```
用途：**导入 Finder**（与 Finder `rules.json` / 记录 schema 一致）· 备份 · 迁移浏览器。

> ⚠️ 脚本**不做**「数据来源核对」（不查服务端是否已删）—— 只负责拉取你看到的、存本地、分类给你看。

## 六、限制（务必知道，避免误判为 bug）

| # | 限制 | 原因 |
| --- | --- | --- |
| 1 | **只覆盖你实际浏览过的分类/时间范围** | 旁听模式：你没滚到的记录不会发请求，因而抓不到 |
| 2 | **数据窗口 ≈ 3 个月** | B站 `history/cursor` 服务端只返回近期数据（结构性天花板） |
| 3 | **想抓更多要滚动** | 每滚一屏触发一页请求；不想主动发请求（省风控额度） |
| 4 | 角标位置在卡片末尾 | B站页面结构决定；可用 `CFG.anchorSelector` 调 |
| 5 | B站改版可能需更新选择器 | `CFG` 里已留兜底链；控制台会打印实际用的选择器 |
| 6 | 长期全量留存靠导出回灌 Finder | 与限制 2 相关：服务端只给 3 个月 |

## 七、常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 页面顶部没有蓝色条 | ① Tampermonkey 没装/没启用 ② 没在 `/history` 页 ③ 元数据被改动 |
| 有顶栏但角标只有「已看完」 | 旧版本（≤0.2.0 有拆包 bug）。更新到 **0.4.1** |
| 「分类」面板显示"暂无记录" | 旧版本（≤0.3.0 的 Promise bug）。更新到 **0.4.1** |
| 悬浮面板每次都自己弹出 | ≤0.4.0 的行为。更新到 **0.4.1**（默认关闭）；或清 `localStorage` 键 `bhf.ui.panels` |
| 顶栏某类是 0 | 悬停读数看**逐条规则命中数** —— 若那条也是 0，说明规则没命中（可在规则抽屉调阈值） |
| 顶栏读数为 0 / 不变 | 页面还没发出历史请求 → **向下滚动**几屏 |
| 角标位置不对/看不见 | 控制台执行 `[BHF] overlay 已启动：… 卡片选择器 X`，把 X 发给开发者调 `CFG` |
| 想确认抓到多少 | 控制台 `BHF.Storage.count()` |
